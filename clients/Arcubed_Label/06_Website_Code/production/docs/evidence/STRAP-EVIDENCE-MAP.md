## Why a generated preview is not permitted here

The brief permits a generated strap preview when "only strap reference
exists". There is no strap reference. Producing one would require inventing
its width, length, construction, colour, hang and — critically — the
attachment points and hardware, none of which appear in any photograph. That
is designing a product, not previewing one.

## Consequence for the storefront

Crochet Strap remains purchasable at its real +5 JOD and is carried through
cart, checkout and order. It produces no visual change. The product page names
what the photograph actually shows so the customer is never misled about what
the image represents.
