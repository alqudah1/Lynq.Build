## Rebuild history

- **Cut-outs** were 1200px and are now **2400px**, rebuilt by `scripts/build-hires.mjs`.
  Colour comes from the 6000x4000 original; the matte is still computed by the proven
  1600px path and resized up to meet it, because a soft mask survives a resize and
  stitch detail does not.
- **Tile cut-outs** (de-haloed, for colour fields) now derive from those 2400px cuts.
- **Macros** were cropped from an already-downscaled 1600px proxy and then upscaled to
  1100px, i.e. roughly 430px of real detail. `scripts/build-textures.mjs` now crops the
  full-resolution original and downsamples. A dedicated wider `macro-metallic` (1937px)
  serves the homepage material moment.
- **Wordmarks** were re-keyed from the client's 2646x756 artwork with flat ink and true
  alpha (`scripts/build-logo.mjs`). Note the mark's own ink occupies only ~1106px of that
  canvas, so its true resolution was never the limiting factor.
