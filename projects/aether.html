How we work

No shortcuts.
No shortcuts.

Every fragrance begins with a brief that can be read in a single sentence. A place, a memory, a feeling with no name. We work the formula until the scent earns it.

We never use synthetic base notes. The production run is fixed before the first bottle is filled. When a fragrance sells out, it retires. No rereleases, no anniversaries, no second chances.
